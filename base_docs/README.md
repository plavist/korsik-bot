# Базовые документы

Положите сюда регламенты и политики (PDF, PPTX, DOCX, TXT, MD, изображения). При запуске сервис `ingest` сам загрузит их в базу знаний
(с распознаванием текста), а файлы, которых в папке больше нет, уберёт из базы. Базовые документы нельзя удалить из панели управления —
только убрав файл из папки.

Другая папка задаётся переменной `BASE_DOCS_DIR` в `.env` (путь на сервере, относительно корня проекта или абсолютный).
Содержимое папки не хранится в git (кроме этого файла).
