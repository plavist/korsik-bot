# Соответствие кейсу «Разработка ИИ-ассистента в мессенджере МАКС для адаптации персонала»

Сверка с `КЕЙС_ПОЛИПЛАСТИК.pdf` (слайды 2, 3, 5, 6). Статус: ✅ реализовано, 🟡 реализовано частично.

## Задачи участников (слайд 2)
| Требование кейса | Статус | Где реализовано |
|---|---|---|
| Миграция в МАКС с сохранением проактивных триггерных рассылок: таймлайн от предложения о работе до конца испытательного срока | ✅ | `scenario.py` (21 этап), планировщик `engine.tick` (проверка каждые 30 с), бот MAX (long polling / webhook) |
| Персонализация под производственные площадки | ✅ | площадки ГрПП / ГТП / Лужники, офис/не офис, «ты/вы», тексты и вложения по площадке |
| RAG для неструктурированных вопросов на естественном языке | ✅ | `agent.py` (агент с поиском по базе знаний), `ingest` (OCR → Qdrant) |
| Sentiment Analysis ответов в пульс-опросах, скрытые проблемы, автоэскалация «красных флагов» | ✅ | `sentiment.py` (тональность, темы, красный флаг), открытые ответы опросов анализируются, автоэскалация в панель управления |
| Контроль «галлюцинаций» | ✅ | ответ только по найденным фрагментам, иначе «в базе нет ответа» + предложение передать HR; цитирование документа и страницы |
| Бесшовная эскалация диалога живому рекрутеру через API МАКС | ✅ | **бесшовная передача без подтверждения**: нет ответа в базе — Корсик молчит и обращение сразу у HR; интент «похоже на эскалацию» и `escalate_to_hr` — ответ + мгновенная передача; **HR получает обращение в МАКС с кнопками и отвечает сотруднику прямо оттуда** (пока HR ведёт диалог, бот молчит и пересылает сообщения сотрудника HR), диалог и ответ из панели тоже работают |

## Роли (слайд 5)
| Роль | Статус | Где |
|---|---|---|
| Новый сотрудник: вопрос в первый день → мгновенная пошаговая инструкция со ссылками | ✅ | RAG-агент, документы из базы знаний |
| HR-менеджер: сводная аналитика (этапы онбординга, темы по тегам), подключается к диалогу только в нестандартных ситуациях | ✅ | вкладка «Аналитика» (интерактивная: фильтры, детализация по клику), «Эскалации» |
| Руководитель подразделения: дашборд статуса адаптации подчинённого + push о личной встрече | ✅ | роль «Руководитель подразделения» (видит только своих), **светофор «Статус адаптации»** (`insights.status`, вкладка «Аналитика»), push на 3-й день, 2 недели, месяц, 2 месяца, за неделю до конца ИС и при высоком риске |
| Руководитель по подбору: еженедельный дайджест «Настроения в коллективе новичков», кластеризация ответов, зоны риска | ✅ | «Аналитика» → дайджест (кластеризация нейросетью), рассылка по понедельникам 9:00 получателям в МАКС |

| Масштаб: до 100%, тиражирование на дочерние структуры | ✅ | площадки добавляются в панели («Сценарий» → «Площадки»), новая может получить содержание «как у» существующей |

## Второстепенные проблемы (слайд 3)
| Проблема | Статус | Решение |
|---|---|---|
| Ручной разбор текстовых ответов HR | ✅ | автоанализ тональности, кластеры тем в дайджесте |
| Нет предиктивной аналитики | ✅ | индекс риска ухода 0–100 по ранним сигналам (флаги, негатив, низкие оценки, обращения, молчание), список «Зона риска» |
| Сложность масштабирования, бот без разработчиков | ✅ | HR сам: загружает регламенты (PDF/PPTX/DOCX), правит тексты, картинки и файлы сценария, команды `/`, роли пользователей панели управления |
