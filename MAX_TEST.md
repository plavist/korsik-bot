# Живое тестирование бота в MAX (для человека, ~15 минут)

Бот: **ХАКАТОН тест 2** — `@id5021013384_4_bot`. Транспорт — long polling (`GET /updates`), публичный адрес не нужен.
Автономный полный тест для Claude — `CLAUDE_TEST_RUNBOOK.md`; здесь — быстрый ручной прогон.

## 0. Проверка перед тестом
Панель управления `http://<ip>:8003` → **Канал → MAX**: токен ✅, бот виден, «Ошибка: нет», время последнего запроса обновляется,
webhook-подписок нет, зарегистрированы команды `/start /hr /food /help`.

## 1. Привязка сотрудника (знакомство по сценарию)
1. Панель управления → **Сотрудники** → «Новый сотрудник»: `ТЕСТ-<ваше имя>`, площадка (ГрПП / ГТП / Лужники), дата выхода → «Добавить».
2. В карточке — ссылка-приглашение `https://max.ru/id5021013384_4_bot?start=КОД`. Откройте её в MAX и нажмите **«Начать»**
   (или отправьте боту `/start КОД`). Либо выберите вашего пользователя в списке «Привязать к пользователю».
3. Сразу приходит знакомство: «Вот чем я могу быть полезен…», «Добро пожаловать в нашу команду!…», вопрос «Как мы будем общаться?» с кнопками.
4. Нажмите «На ТЫ» (или «На ВЫ» — дальше всё на «вы») → документы для выхода (для ГТП — 9 пунктов с фото), вопрос про транспорт, факты о компании.

## 2. Этапы сценария без ожидания
В карточке сотрудника у любого этапа кнопка **«Отправить сейчас»** (или «Отправить следующий этап»). Что посмотреть:

| Этап | Что проверить |
|---|---|
| За день до выхода | вопрос «Ты готов?» с тремя вариантами, на «Да, но немного волнуюсь» — тёплый ответ |
| Первый день: доступы | «Нет» → текст про руководителя + кнопки HR + эскалация в панели управления |
| Первый день: обед | «Нет, спасибо!» → подсказка про `/Food` |
| Опрос 3-го дня | три вопроса, ветки А/Б/В, кнопки «Передать HR через Корсика» / «Связаться с рекрутером» |
| Чек 2 недель | шкалы 1–10 (два ряда кнопок); оценка < 8 → бот просит причину; «да/нет» |
| Опрос 2 месяцев | мульти-выбор («Готово ✔»), «Свой вариант», итоговые реплики по ответам |
| Конец испытательного срока | ветки «Не уверен» / «задумываюсь об уходе» → кнопка «готов озвучить лично», 9 шкал, прощание |

## 3. Время и напоминания (без ожидания суток)
Карточка → «Тест: сейчас по Москве» → выберите время (например, дата выхода 10:01) → **«Прогнать планировщик»** — придёт этап, который
должен уйти в это время. «Состарить неотвеченный опрос на 25 ч» + прогон → придёт напоминание «Пишу с небольшим напоминанием…».

## 4. Свободные вопросы и стиль
Задайте боту: «Во сколько начинается рабочий день?», «Сколько дней отпуска?», «Можно ли принимать подарки от поставщиков?»,
«Какой пароль от wifi?», «Сколько мне заплатят?», «Я очень устал, никто не помогает», «Хочу поговорить с живым человеком».
Ожидаем: короткие ответы со ссылкой на документ и страницу; на вопрос без ответа в базе — тишина в чате, но обращение в панели управления; мужской род («передал»);
на «вы» — если выбрали «вы».

## 4а. Бесшовная передача HR — без кнопок и подтверждений
- «Какой пароль от wifi?» → **в чат ничего не приходит**; в панели управления (Эскалации) сразу появилось обращение «нет ответа в базе — передано автоматически» с текстом вопроса.
- «Сколько мне заплатят?» → бот пишет, что передал вопрос коллегам (без кнопок); обращение в панели появилось сразу.
- В опросе кнопка «Передать HR через Корсика» → напишите текст → сразу «Передал!» и обращение «написал через Корсика» («Не передавать» до отправки текста отменяет).
- `/HR` → сразу «Передал твой запрос…», обращение «команда /HR».
- «Связаться с рекрутером» — тоже сразу.
- Технический сбой (например, остановлен `ingest`) → «технические неполадки», обращение **не** создаётся.

## 4в. HR отвечает прямо в МАКС
1. Панель управления → **Эскалации** → «Обращения HR прямо в МАКС»: впишите свой MAX ID (его покажет команда `/myid`), «Сохранить», «Отправить тест» — в МАКС придёт «Вы подключены как получатель…».
2. С другого аккаунта задайте боту вопрос без ответа («Какой пароль от wifi?») — вам в МАКС придёт «🔔 Новое обращение №…» с кнопками «Ответить», «Взять в работу», «Закрыть обращение»; сотруднику ничего не пришло.
3. «Ответить» → напишите текст → у сотрудника появилось «Ответ HR-специалиста: …», вам — «✅ Ответ отправлен».
4. Сотрудник пишет «спасибо, жду» — бот не отвечает, вам приходит «💬 Сообщение по обращению №…». «Закрыть обращение» → бот снова отвечает сам.

## 4б. Команды из панели управления
Панель управления → **Команды**: добавьте `transport` (обычная: свой текст, либо «из базы знаний» с запасным ответом), нажмите «Проверить» — увидите вывод.
Через несколько секунд при вводе «/» в MAX появится новая подсказка; `/help` перечислит её. Править/удалять можно в любой момент;
встроенные (`start`, `hr`, `food`, `help`) — только править.

## 5. Ответ HR в мессенджер
Панель управления → **Эскалации** → откройте обращение → прочитайте весь диалог → ответьте → в MAX приходит «Ответ HR-специалиста: …».

## 6. Команды
Введите `/` — должны показаться подсказки: `/start`, `/hr`, `/food`, `/help` (+ ваши команды из панели управления).

## Если что-то не работает
| Симптом | Что делать |
|---|---|
| Нет кнопок / не нажимаются | панель управления → Канал → «Последние события от MAX» (JSON `message_callback`) и «Ошибка» |
| Бот молчит | статус MAX (токен, polling); подписка webhook (кнопка «Отключить webhook-подписку»); LLM отвечает 10–60 с |
| `CERTIFICATE_VERIFY_FAILED` | сертификаты Минцифры включены в образ pipeline; на другом сервере задайте `MAX_CA_BUNDLE` |
| Не пришли подсказки `/` | «Зарегистрировать команды (/)» в Канале, перезайти в чат |

## Продакшен: webhook
Нужен домен с HTTPS на 443 и доверенным сертификатом. `.env`: `MAX_TRANSPORT=webhook`, `MAX_WEBHOOK_SECRET=…` (**обязателен**: без него вебхук отвечает 503 и подписка не создаётся); проксировать
`https://<домен>/max/webhook` → `pipeline:8004/max/webhook`; подписка: `POST /api/pipeline/api/max/subscribe {"url": "https://<домен>/max/webhook"}`.
Polling при активной подписке не работает (ограничение MAX).
