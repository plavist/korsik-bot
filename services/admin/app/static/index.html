Команды бота

      
Подсказки, которые появляются у сотрудника при вводе «/». Встроенные команды можно изменять, но не удалять. Свои команды:
        обычная — фиксированный ответ, из базы знаний — Корсик ищет ответ по запросу (если в базе пусто — отвечает запасным текстом). В ответе доступно {name} — имя сотрудника.
        После сохранения подсказки автоматически обновляются в MAX.
